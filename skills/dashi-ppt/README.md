# Dashi PPT

Dashi PPT 是一個本地 PPT 生成助手。你給它一個彙報目標、受眾、頁數和內容重點,它會從已接入的視覺頁面中組合出一份可離線開啟、可翻頁、可編輯和可匯出的 HTML PPT。

當前版本: `0.4.14`

## 它適合做什麼

- 行業研究、融資復盤、競品分析和趨勢報告
- 專案彙報、方案展示、路演材料和內部培訓
- 需要快速形成結構完整、視覺統一、可繼續編輯的簡報

## 你會得到什麼

- 一份本地 HTML PPT,開啟後即可橫向翻頁
- 預覽頁裡可以繼續改文字、換圖片/影片、調整頁面屬性
- 你提供的圖片/影片會寫入本次 deck,成品不依賴原始素材路徑
- 可以匯出 HTML、PDF 或 PPTX
- 所有輸出都儲存在本機,適合繼續歸檔、修改或交付

## 怎麼使用

安裝後,在 Codex/Agent 裡說明要使用 `dashi-ppt`,然後直接描述你想做的 PPT:

- 主題和目標
- 面向誰彙報
- 希望幾頁
- 想突出的結論或內容
- 偏好的視覺風格

如果你沒有指定風格,Skill 會先列出可選風格讓你選擇,不會直接替你決定。

## 安裝說明

把整個 `dashi-ppt` 目錄放到本機 Skill 目錄中,然後重新開啟會話即可使用。

本機需要能執行 Node.js 20+ 和 npm。首次生成時依賴會自動準備。
