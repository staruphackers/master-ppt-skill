# Layout Roles

`role` 只用於前三個模板方案的草稿選頁。面向使用者交付前,每個邏輯頁必須落成 3 個具體 `layout` 模板方案和 1 個無 layout 的 bespoke 方案。

| role | 用途 |
|---|---|
| `cover` | 封面,1 個邏輯封面頁從當前主題前 5 頁中選擇 3 個模板方案 |
| `statement` | 摘要、論點、金句、核心判斷 |
| `breakdown` | 目錄、結構拆解、篇章卡、問答結構 |
| `transition` | 章節分隔、附錄分隔 |
| `context` | 市場背景、定位矩陣、區域畫像、批註說明 |
| `metrics` | 核心數字、指標、計量條、計分榜 |
| `trend` | 資金流、時間線、階段、季度走勢 |
| `comparison` | 交叉透視、同比、對決、表格、多維對比 |
| `distribution` | 比例帶、輪次、漏斗、市佔、梯隊、結構演變 |
| `relationship` | 聯投、層級、網路、交集、徑向關係 |
| `case` | 典型案例、分屏、分鏡、影像速寫、人物證言 |
| `image` | 全景、拼貼、陳列、畫廊、圖片主導頁 |
| `process` | 產業鏈、流向、用途、階段、實施路徑 |
| `risks` | 風險研判、預測、關鍵問答 |
| `observation` | 投資展望、核心結論、觀點引述、專題洞察 |
| `ambient` | 動態背景、氛圍頁、視覺章節頁 |
| `actions` | 應用落地、方案、路線、下一步 |
| `result` | 核心結論、數字海報、核心要點 |
| `team` | 團隊、關於我們 |
| `closing` | 結尾頁 |

真實模板候選以 `layout:query` 輸出為準。v4 不參與 role 匹配,由 Agent 按目標、受眾、敘事和主題單獨設計。直接指定模板頁時使用當前 key,例如 `theme01_page001`、`theme12_page001`。
